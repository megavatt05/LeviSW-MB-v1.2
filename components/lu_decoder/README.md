# Декодер импульсов LU (платформенно-независимый)

Файл `lu_decoder.c` содержит конечный автомат на чистом C. Он не зависит от ESP-IDF, GPIO, FreeRTOS, I2C, SPI или пакета поддержки платы. Приложение ESP передаёт декодеру монотонные временные метки фронтов LU и периодически вызывает `lu_decoder_poll()` во время пауз между событиями.

## Предварительный профиль декодирования

Профиль по умолчанию основан на исторических стендовых заметках, а не на опубликованной спецификации протокола домофона:

- отклонять переход, если до истечения 120 мкс сигнал возвращается к предыдущему уровню;
- завершать пакет после 80 мс без подтверждённого фронта;
- считать две подтверждённые смены уровня одним импульсным номером квартиры;
- принимать полученные номера квартир в диапазоне 1..80.

Все временные интервалы и делитель количества переходов на номер настраиваются. Перед разрешением коммутации матрицы их необходимо проверить на реальной панели осциллографом или логическим анализатором. Декодер сообщает только предполагаемый номер квартиры; он не активирует реле, драйверы, шины питания или точки коммутации.

Потеря одного перехода приводит к последовательности с повторяющимся уровнем, которая отклоняется. Потерю целого импульса (двух переходов) невозможно обнаружить только по количеству импульсов: такая последовательность неотличима от меньшего номера квартиры. Для надёжного обнаружения этой ошибки требуется правило кадрирования или контрольной суммы со стороны панели либо подтверждённое временное/кодовое ограничение, которое пока не документировано.

## Автономные тесты на ПК

```sh
cmake -S components/lu_decoder/tests -B build/lu_decoder_tests
cmake --build build/lu_decoder_tests
ctest --test-dir build/lu_decoder_tests --output-on-failure
```

Тесты проверяют все адреса 1..80, короткую помеху, отфильтрованную по длительности, потерю одного перехода, неоднозначность при потере целого импульса и код вне допустимого диапазона.
