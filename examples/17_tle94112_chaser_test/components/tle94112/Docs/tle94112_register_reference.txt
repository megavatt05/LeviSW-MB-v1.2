[1] HB_ACT_1_CTRL (0x03) - Активация каналов 1-4

    7    4      HB4_LS_EN               1=вкл, 0=выкл

════════════════════════════════════════════════════════════════════════════════════
SPI ПРОТОКОЛ
════════════════════════════════════════════════════════════════════════════════════

ФОРМАТ КОМАНДЫ:

    Байт 0: [OP | A6 | A5 | A4 | A3 | A2 | A1 | A0]
            ──  ────────────────────────────────
            OP = Operation Bit:
                 0 = READ операция
                 1 = WRITE или READ&CLEAR операция
            A6:A0 = 7-битный адрес регистра

    Байт 1: [D7 | D6 | D5 | D4 | D3 | D2 | D1 | D0]
            При WRITE: данные для записи
            При READ:  данные из регистра

ПРИМЕРЫ:

    READ SYS_DIAG_1 (0x1B):
    ─────────────────────
    TX: 0x1B  (OP=0, A6:A0=0x1B)
    RX: 0xXX  (значение регистра)

    WRITE HB_ACT_1_CTRL (0x03):
    ──────────────────────────
    TX: 0x83  (OP=1, A6:A0=0x03)
    TX: 0x06  (данные: HB1 HS+LS enabled)
    RX: 0x06  (эхо данных)

════════════════════════════════════════════════════════════════════════════════════
ВСПОМОГАТЕЛЬНАЯ ИНФОРМАЦИЯ
════════════════════════════════════════════════════════════════════════════════════

ПАРАМЕТРЫ SPI:
- Максимальная частота: 5 МГц
- Рекомендуемая частота: 1 МГц
- Режим: SPI Mode 1 (CPOL=0, CPHA=1)
- Порядок бит: LSB-first
- Напряжение: 5V или 3.3V (см. документацию)

РЕЖИМЫ РАБОТЫ:

1. SLEEP режим (EN=LOW):
   - Все выходы отключены
   - Микросхема потребляет минимум энергии
   - SPI доступен для чтения статуса

2. NORMAL режим (EN=HIGH):
   - Микросхема работает полностью
   - Доступно управление всеми каналами
   - Активны все функции защиты

ТИПИЧНАЯ ПОСЛЕДОВАТЕЛЬНОСТЬ ИНИЦИАЛИЗАЦИИ:

1. Установить EN=LOW (sleep mode)
2. Инициализировать SPI
3. Установить EN=HIGH (normal mode)
4. Подождать ~200 ms для стабилизации
5. Читать SYS_DIAG_1 для проверки ошибок
6. Писать HB_ACT_1_CTRL для активации каналов
7. Писать PWM коэффициенты если нужно
8. Читать статус регулярно
