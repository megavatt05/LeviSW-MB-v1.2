💡 ПРИМЕРЫ ИСПОЛЬЗОВАНИЯ В КОДЕ:
═══════════════════════════════════════════════════════════════════════════════════

#include "tle94112_registers.h"

void my_function(void) {
    tle94112_status_t status = {0};
    
    // Читаем регистры через SPI
    uint8_t sys_diag1 = read_register(SYS_DIAG_1);
    uint8_t oc_status = read_register(SYS_DIAG_OC_1_4);
    
    // Декодируем
    tle94112_decode_status1(sys_diag1, &status);
    tle94112_decode_status2(oc_status, &status);
    
    // Проверяем ошибки
    if (status.over_temp) {
        printf("ПЕРЕГРЕВ!\n");
    }
    
    // Проверяем канал
    if (status.over_current[0]) {
        printf("Over current на CH1!\n");
    }
    
    // Выводим полный статус
    tle94112_print_status(&status);
}

Проблема: Ошибка при компиляции "The system cannot find the path specified"
Решение:  Это ошибка в задаче сборки VS Code (указана неправильная папка).
          Выполните сборку из командной строки:
          cd C:\Users\haf85\esp\ESPUMAN && idf.py build

Проблема: Нет вывода в терминал
Решение:  1. Проверьте COM порт (в Device Manager)
          2. Проверьте скорость передачи (115200 baud)
          3. Переподключитесь к последовательному портуПроблема: "Failed to read register"
Решение:  1. Проверьте подключение всех пинов SPI
          2. Проверьте напряжение 3.3V/5V на TLE94112
          3. Убедитесь, что пин EN установлен на HIGH
          4. Снизьте частоту SPI до 500 кГц для тестирования

Для полного списка решений смотрите TLE94112_QUICK_REFERENCE.md
