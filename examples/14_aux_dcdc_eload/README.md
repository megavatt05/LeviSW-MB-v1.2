# Пример 14: Вспомогательные DC-DC L1/V5 и коррекция порога L1ADJ (LeviSW-MB v1.2)

Данный проект демонстрирует работу вспомогательных импульсных стабилизаторов `DP1 / DP2` (`LM22675MRX-5.0`), эквивалента нагрузки (`eLOAD`) и цифрового потенциометра `DA4 MCP4532` (`0x2F`) для коррекции порога `L1ADJ` через аппаратный **Узел 14** (Лист 9 `Power.SchDoc` принципиальной схемы платы **LeviSW-MB v1.2**).

Поддерживаемая среда: **ESP-IDF >= 5.2** (целевой микроконтроллер: `ESP32-PICO-V3`).

---

## Архитектура и схемотехника Узла 14

### 1. Вспомогательные стабилизаторы `DP1`, `DP2` (`LM22675MRX-5.0`) и эквивалент нагрузки (`eLOAD`)
- **Назначение**: формирование вспомогательных питающих напряжений `L1` / `V5` и подключение эквивалента нагрузки `eLOAD`.
- **Управление**:
  - Сигнал разрешения **`CEN_L1`** (`eLOADEN`) управляется битом **`P0.0`** расширителя `DD3 TCA9535` (`0x20`, контрольная точка `TP59`).
  - Цифровой потенциометр **`DA4 MCP4532`** (адрес I2C **`0x2F`**) устанавливает уставку коррекции порога срабатывания `L1ADJ`.

---

## Сборка и запуск примера

1. Откройте терминал с настроенным окружением ESP-IDF (>= 5.2):
```bash
cd examples/14_aux_dcdc_eload
idf.py set-target esp32
idf.py build
```

2. Выполните прошивку и откройте монитор порта:
```bash
idf.py flash monitor
```
