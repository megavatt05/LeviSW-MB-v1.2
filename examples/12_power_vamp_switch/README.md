# Пример 12: Входная защита питания и ключ усилителя +Vamp (LeviSW-MB v1.2)

Данный проект демонстрирует работу цепей защиты питания и электронного ключа коммутации питания аудиоусилителя `+Vamp` через транзисторы `VT4/VT5` с помощью аппаратного **Узла 12** (Лист 7 `Power.SchDoc` принципиальной схемы платы **LeviSW-MB v1.2**).

Поддерживаемая среда: **ESP-IDF >= 5.2** (целевой микроконтроллер: `ESP32-PICO-V3`).

---

## Архитектура и схемотехника Узла 12

### 1. Ключ питания усилителя `+Vamp` (`VT4`, `VT5`)
- **Назначение**: коммутация силового питания дочерней платы усилителя (`+Vamp`) по команде микроконтроллера.
- **Схема управления**:
  - Сигнал управления **`VAMPON`** поступает с порта **`P0.4`** расширителя `DD3 TCA9535` (`0x20`). Контрольные точки: `TP63`, `TP153`.
  - Фактическое напряжение питания `+Vamp` измеряется измерительной цепью `VAmpM` на выводе `GPIO34 / ADC1_CH6` (контрольные точки `TP81`, `TP94`) через резистивный делитель `510 кОм / 75 кОм` (`×7.8`).

---

## Сборка и запуск примера

1. Откройте терминал с настроенным окружением ESP-IDF (>= 5.2):
```bash
cd examples/12_power_vamp_switch
idf.py set-target esp32
idf.py build
```

2. Выполните прошивку и откройте монитор порта:
```bash
idf.py flash monitor
```
