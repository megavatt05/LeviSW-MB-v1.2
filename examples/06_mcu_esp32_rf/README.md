# Пример 06: Центральный микроконтроллер ESP32 и RF-тракт (LeviSW-MB v1.2)

Данный проект демонстрирует инициализацию и диагностику центрального микроконтроллера `DD4` (`ESP32-PICO-V3`) и беспроводного RF-тракта через аппаратный **Узел 06** (Лист 4 `MCU-ESP.SchDoc` принципиальной схемы платы **LeviSW-MB v1.2**).

Поддерживаемая среда: **ESP-IDF >= 5.2** (целевой микроконтроллер: `ESP32-PICO-V3`).

---

## Архитектура и схемотехника Узла 06

### 1. Центральный микроконтроллер DD4 (`ESP32-PICO-V3`, LGA-48)
Микроконтроллер со встроенной флеш-памятью и радиочастотным трактом является ядром материнской платы домофонного коммутатора.

#### Ключевые схемные цепи и интерфейсы на Листе 4 (`MCU-ESP.SchDoc`):
- **Интерфейс программирования и отладки (`XP5`)**:
  - `U0TX` (`GPIO1`, `TP105/TP116`), `U0RX` (`GPIO3`, `TP106/TP117`), `BOOT` (`GPIO0`, `TP104`, pull-up `RN16` 10 кОм).
- **Интерфейс JTAG (`XP4`)**:
  - `JTCK` (`GPIO13`, `TP91`), `JTMS` (`GPIO14`, `TP92` — также аналоговый вход контроля версии PCB `VersionPCB`).
- **Шина I2C-L (`IO32=SCL0`, `IO33=SDA0`)**:
  - Внешняя подтяжка резисторной сборкой `RN15` (10 кОм к `+3.3V`) для опроса расширителя `DD3`, потенциометров `DA2..DA4` и мониторов `DD5/DD6`.
- **Шина SPI2 (`IO7=MOSI`, `IO9=MISO`, `IO5=CLK`, `CS1`, `CS2`, `EN-DE`)**:
  - Управление драйверами матрицы `D1` и `D2`.
- **RF-тракт и антенна**:
  - Встроенная согласующая цепь радиоканала 2.4 ГГц (`Wi-Fi / Bluetooth`) микросхемы `ESP32-PICO-V3` с разводкой на печатной плате для стабильной беспроводной связи.

---

## Сборка и запуск примера

1. Откройте терминал с настроенным окружением ESP-IDF (>= 5.2):
```bash
cd examples/06_mcu_esp32_rf
idf.py set-target esp32
idf.py build
```

2. Выполните прошивку и откройте монитор порта:
```bash
idf.py flash monitor
```
