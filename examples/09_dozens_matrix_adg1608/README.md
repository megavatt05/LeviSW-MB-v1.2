# Пример 09: Коммутатор десятков и диодная защита линий D0–D7 (LeviSW-MB v1.2)

Данный проект демонстрирует коммутацию линий десятков координатной матрицы `D0..D7` через аналоговый мультиплексор `DA1 ADG1608BR` и работу диодной защиты через аппаратный **Узел 09** (Лист 5 `D8-OUT.SchDoc` принципиальной схемы платы **LeviSW-MB v1.2**).

Поддерживаемая среда: **ESP-IDF >= 5.2** (целевой микроконтроллер: `ESP32-PICO-V3`).

---

## Архитектура и схемотехника Узла 09

### 1. Коммутатор десятков `DA1` (`ADG1608BR`)
- **Назначение**: выбор одного из 8 каналов десятков (`D0..D7`) абонентской матрицы для подключения к силовой шине коммутатора.
- **Схема подключения**:
  - Управляется адресными сигналами `SW-A0..SW-A2` и сигналом разрешения `SW-EN`, поступающими с портов `P0`/`P1` расширителя `DD3 TCA9535` (`0x20`).
  - Клеммник десятков: **`XP2:1..8`** (`D0..D7`, контрольные точки **`TP27..TP34`**).

---

### 2. Диодная защита линий `D0–D7`
- **Назначение**: предотвращение выхода из строя ключей мультиплексора и портов платы при возникновении статического электричества, наводок или перенапряжений со стороны длинных абонентских линий кабельной сети подъезда.

---

## Сборка и запуск примера

1. Откройте терминал с настроенным окружением ESP-IDF (>= 5.2):
```bash
cd examples/09_dozens_matrix_adg1608
idf.py set-target esp32
idf.py build
```

2. Выполните прошивку и откройте монитор порта:
```bash
idf.py flash monitor
```
