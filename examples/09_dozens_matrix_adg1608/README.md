# Пример 09 (историческое имя каталога): Проверка AMP1–AMP8 через ADG1608

Уточнённое назначение по исходной КД: пример перебирает аналоговые каналы `AMP1..AMP8` через `DA1 ADG1608BR` (лист D8). Координатные линии `D0..D7` на `XP2` подключены к MC33879 и этим примером **не переключаются**. Название папки сохранено для совместимости со старыми инструкциями.

Поддерживаемая среда: **ESP-IDF >= 5.2** (целевой микроконтроллер: `ESP32-PICO-V3`).

---

## Архитектура и схемотехника Узла 09

### 1. Аналоговый селектор `DA1` (`ADG1608BR`)
- **Назначение**: выбор одного из восьми маршрутов `+LINE → AMP1..AMP8` на внешнюю плату `LeviAMP` через разъём `XS3`.
- **Схема подключения**:
  - `+LINE → VD6 → ADG1608:D`; выходы `S1..S8` продолжаются в `AMP1..AMP8`.
  - Управление `SW-A0..SW-A2/SW-EN` поступает с портов `P0/P1` расширителя `DD3 TCA9535` (`0x20`).
  - Это не селектор D0..D7 и не коммутатор XP2.

---

### 2. Что тест НЕ проверяет
- Не включает и не отключает силовые выходы `MC33879`.
- Не проверяет линии `D0..D7` на `XP2`, защитные элементы VD7..VD14 или матрицу `8×10`.
- Не проверяет `E0..E9` / `TLE94112EL`.

**Предупреждение:** при `SW-EN=1` ADG1608 соединяет вход `+LINE` с выбранным маршрутом AMP. Не запускать на действующей линии/подключённой трубке до проверки монтажного варианта RN22…RN26 и уровней внешнего аудиоблока.

---

## Сборка и запуск примера

1. Откройте терминал с настроенным окружением ESP-IDF (>= 5.2):
```bash
cd examples/09_dozens_matrix_adg1608  # историческое имя папки; тестирует AMP1..AMP8
idf.py set-target esp32
idf.py build
```

2. Выполните прошивку и откройте монитор порта:
```bash
idf.py flash monitor
```
