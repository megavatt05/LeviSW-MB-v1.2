# Пример 13: Основной 3-канальный DC-DC преобразователь (LeviSW-MB v1.2)

Данный проект демонстрирует управление и мониторинг основного 3-канального синхронного понижающего преобразователя `D3 TPS65261RHBR`, цифровых потенциометров `MCP4532` и измерителей телеметрии `INA226` через аппаратный **Узел 13** (Лист 8 `Power.SchDoc` принципиальной схемы платы **LeviSW-MB v1.2**).

Поддерживаемая среда: **ESP-IDF >= 5.2** (целевой микроконтроллер: `ESP32-PICO-V3`).

---

## Архитектура и схемотехника Узла 13

### 1. Основной DC-DC конвертер `D3` (`TPS65261RHBR`)
- **Назначение**: формирование основных стабилизированных напряжений питания `+V1`, `+V2` и дополнительных шин платы.
- **Цифровые потенциометры регулировки (`MCP4532`)**:
  - `DA2` (адрес `0x2C`) — настройка уставки шины `+V1`.
  - `DA3` (адрес `0x2D`) — настройка уставки шины `+V2`.
- **Измерители телеметрии (`INA226`)**:
  - `DD5` (адрес `0x40`, шунт `R51 = 20 мОм`) — контроль тока, напряжения и мощности по шине `+V1`.
  - `DD6` (адрес `0x41`, шунт `R62 = 20 мОм`) — контроль тока, напряжения и мощности по шине `+V2`.
- **Сигнал Power Good (`PG`)**:
  - Заведен на вывод `P0.1` расширителя `DD3 TCA9535` (`TP60`), позволяя микроконтроллеру контролировать исправность питания.

---

## Сборка и запуск примера

1. Откройте терминал с настроенным окружением ESP-IDF (>= 5.2):
```bash
cd examples/13_tps65261_dcdc
idf.py set-target esp32
idf.py build
```

2. Выполните прошивку и откройте монитор порта:
```bash
idf.py flash monitor
```
