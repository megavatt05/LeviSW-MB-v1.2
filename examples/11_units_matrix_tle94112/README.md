# Пример 11: Коммутатор единиц E0–E9 и фильтр возврата -LINE (LeviSW-MB v1.2)

Данный проект демонстрирует коммутацию линий единиц координатной матрицы `E0..E9` через интеллектуальный драйвер `D2 TLE94112EL` и работу фильтра возврата `-LINE` через аппаратный **Узел 11** (Лист 6 `E10-OUT.SchDoc` принципиальной схемы платы **LeviSW-MB v1.2**).

Поддерживаемая среда: **ESP-IDF >= 5.2** (целевой микроконтроллер: `ESP32-PICO-V3`).

---

## Архитектура и схемотехника Узла 11

### 1. Драйвер единиц `D2` (`TLE94112EL`)
- **Назначение**: 12-полумостовой интеллектуальный коммутатор нагрузки, управляемый по шине `SPI2`, предназначенный для коммутации линий единиц `E0..E9` (`XP3:1..10`, контрольные точки `TP35..TP44`) и вспомогательных цепей (`SW-OUT2`, `SW-OUT12`).
- **Нелинейная таблица маппинга единиц в BSP**:
  - `E0` (`XP3:1`, `TP35`) $\to$ полумост `PO1`;
  - `E1` (`XP3:2`, `TP36`) $\to$ полумост `PO5`;
  - `E2` (`XP3:3`, `TP37`) $\to$ полумост `PO7`;
  - `E3` (`XP3:4`, `TP38`) $\to$ полумост `PO9`;
  - `E4` (`XP3:5`, `TP39`) $\to$ полумост `PO6`;
  - `E5` (`XP3:6`, `TP40`) $\to$ полумост `PO4`;
  - `E6` (`XP3:7`, `TP41`) $\to$ полумост `PO3`;
  - `E7` (`XP3:8`, `TP42`) $\to$ полумост `PO10`;
  - `E8` (`XP3:9`, `TP43`) $\to$ полумост `PO11`;
  - `E9` (`XP3:10`, `TP44`) $\to$ полумост `PO8`.

---

## Сборка и запуск примера

1. Откройте терминал с настроенным окружением ESP-IDF (>= 5.2):
```bash
cd examples/11_units_matrix_tle94112
idf.py set-target esp32
idf.py build
```

2. Выполните прошивку и откройте монитор порта:
```bash
idf.py flash monitor
```
