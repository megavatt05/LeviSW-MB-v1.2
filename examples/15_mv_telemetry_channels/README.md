# Пример 15: Каналы цифрового управления и телеметрии MV1, MV1e, MV2 (LeviSW-MB v1.2)

Данный проект демонстрирует работу трех каналов цифрового регулирования питания и телеметрии `MV1`, `MV1e` и `MV2` через аппаратный **Узел 15** (Листы 8, 9, 10 `ManageChannel.SchDoc` принципиальной схемы платы **LeviSW-MB v1.2**).

Поддерживаемая среда: **ESP-IDF >= 5.2** (целевой микроконтроллер: `ESP32-PICO-V3`).

---

## Архитектура и схемотехника Узла 15

### 1. Каналы регулирования и телеметрии
- **Канал MV1 (`+V1`)**:
  - Цифровой потенциометр **`DA2 MCP4532`** (адрес I2C **`0x2C`**) управляет цепочкой обратной связи `FB1` для формирования шины `+V1` (резисторы `R41=75к`, `R42=4.7к`).
  - Прецизионный двунаправленный монитор **`DD5 INA226`** (адрес I2C **`0x40`**) измеряет ток (шунт `R51 = 20 мОм`), напряжение и мощность шины `+V1`. Прерывание `INT1` подключено к `GPIO38` (`TP98`).
- **Канал MV2 (`+V2`)**:
  - Цифровой потенциометр **`DA3 MCP4532`** (адрес I2C **`0x2D`**) управляет цепочкой обратной связи `FB2` для шины `+V2` (`R52=75к`, `R53=4.7к`).
  - Прецизионный монитор **`DD6 INA226`** (адрес I2C **`0x41`**) измеряет параметры по шунту `R62 = 20 мОм`. Прерывание `INT2` подключено к `GPIO39` (`TP99`).
- **Канал MV1e (`Uload / eLOAD`)**:
  - Цифровой потенциометр **`DA4 MCP4532`** (адрес I2C **`0x2F`**) задает порог `Uload` (`R63=75к`, `R64=4.7к`).
  - *Примечание*: Микросхема `DD7 INA226` с шунтом `R73 = 20 мОм` в канале `MV1e` на плате является неподпаиваемой (**DNP**), телеметрия тока по этому каналу не задействована.

---

## Сборка и запуск примера

1. Откройте терминал с настроенным окружением ESP-IDF (>= 5.2):
```bash
cd examples/15_mv_telemetry_channels
idf.py set-target esp32
idf.py build
```

2. Выполните прошивку и откройте монитор порта:
```bash
idf.py flash monitor
```
