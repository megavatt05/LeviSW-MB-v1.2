# Пример 03: Дифференциальный трансивер шины RS-485 (LeviSW-MB v1.2)

Данный проект демонстрирует программную настройку и обмен данными по дифференциальной шине RS-485 через аппаратный **Узел 03** («Дифференциальный трансивер шины RS-485», Лист 3 принципиальной схемы `Com-485-LU-1W.SchDoc` платы **LeviSW-MB v1.2**).

Поддерживаемая среда: **ESP-IDF >= 5.2** (целевой микроконтроллер: `ESP32-PICO-V3`).

---

## Архитектура и схемотехника Узла 03

### 1. Трансивер RS-485 DD2 (MAX13487EESA+)
На материнской плате установлен высоконадёжный полудуплексный трансивер RS-485 `DD2 MAX13487EESA+`, обладающий функцией **AutoDirection** (автоматическое определение направления передачи без необходимости задействовать отдельный пин `R/DE`).

#### Подключения к микроконтроллеру DD4 (`ESP32-PICO-V3`):
- **Линия DI (вход данных передачи)**: подключена к `U1TXD (GPIO2)` через установленную резисторную сборку `RN8` (1 кОм). Контрольные точки: `TP52`, `TP85`.
- **Линия RO (выход данных приёма)**: подключена к `U1RXD (GPIO4)` через сборку `RN8` (1 кОм). Контрольные точки: `TP53`, `TP86`.
- **Линия nSHDN (разрешение работы / Shutdown)**: управляется сигналом `RS-ON` от `GPIO27` через резистор `R11` (1 кОм). Подтяжка к питанию `+3.3V` осуществляется резисторной сборкой `RN5` (10 кОм). Контрольные точки: `TP55`, `TP89`.

---

### 2. Защита линии и согласующие элементы
- **Самовосстанавливающиеся предохранители FR1, FR2 (100 мА / 30 В / 15 Ом)**: включены последовательно по линиям дифференциальной пары `A` и `B` для защиты от перегрузок по току и ошибочных подключений питания. Контрольные точки дифференциальной линии: `TP48 (A)`, `TP49 (B)`.
- **TVS-диодная сборка FS1 (5 В / 16 А)**: защищает входные цепи трансивера от высоковольтных электростатических разрядов (ESD) и импульсных грозовых наводок на длинной абонентской линии.
- **Согласующий резистор R5 (120 Ом)**: устанавливается на концах линии связи для предотвращения отражений сигнала.
- **Фильтрующие конденсаторы C1, C2 (18 пФ) и кварцевые/сигнальные RC-цепочки**: обеспечивают подавление высокочастотных помех на линиях `DI`/`RO`.

## Сборка и запуск примера

1. Откройте терминал с настроенным окружением ESP-IDF (>= 5.2):
```bash
cd examples/03_rs485_transceiver
idf.py set-target esp32
idf.py build
```

2. Выполните прошивку и откройте монитор порта:
```bash
idf.py flash monitor
```
