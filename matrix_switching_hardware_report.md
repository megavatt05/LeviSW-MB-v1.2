# Технический отчет: Аппаратная архитектура и режим бесконфликтной коммутации матрицы (Вариант 2)

Плата: **LeviSW-MB v1.2** (Комплект документации `U210001-A E3`)  
Микроконтроллер: **ESP32-PICO-V3** (LGA-48)  
Дата верификации на стенде: **18 ноября 2026 г.**  
Статус режима: **Аппаратно подтвержден на реальном железе (ток 21.8–41.8 мА, напряжение 8.75 В)**

---

## 1. Введение и постановка проблемы (The Body Diodes Trap)

### 1.1. Физика паразитной фоновой засветки в исходной схеме
В исходном варианте стенда общий анод светодиодной гребенки подключался напрямую к внешнему лабораторному источнику питания $+12\text{ В}$, а катоды заводились на координатный клеммник единиц **`XP3:1..10`** (контролируемый 12-канальным полумостовым драйвером **`Infineon TLE94112EL`**).

```
   +12V (Внешний источник)
     |
     +---------+---------+---------+
     |         |         |         |
    [LED1]    [LED2]    [LED3]    [LED_целевой]
     |         |         |         |
   XP3:1     XP3:2     XP3:3     XP3:7 (PO3)
     |         |         |         |
+----+---------+---------+---------+--------------------+
|               TLE94112EL                              |
|                                                       |
|   PO1       PO5       PO7       PO3 (HB3)             |
|    |         |         |         |                    |
|    +--|>|----+--|>|----+--|>|----+--|>|--+            |
|       |         |         |         |    |            |
|       |      (High-Side Body Diodes)    |            |
|       |         |         |         |    v            |
|   [Hi-Z]    [Hi-Z]    [Hi-Z]     [LS ON] Vs1/Vs2 (+V1)|
|                                    |                  |
|                                   GND                 |
+-------------------------------------------------------+
```

Каждый полумост `TLE94112EL` аппаратно содержит внутренние паразитные встречно-параллельные защитные диоды (Body Diodes) полевых МОП-транзисторов:
* **High-Side диод**: катод соединен с внутренней силовой шиной микросхемы $V_{S1} / V_{S2}$ (линия `+V1` платы через диодный мост `VD24`), анод — с выходным выводом `POx`.
* При подаче на анод светодиодов внешнего напряжения $+12\text{ В}$ и питании внутренней шины драйвера напряжением $V_s \approx 6.5\dots 7.8\text{ В}$ возникает разность потенциалов:
$$\Delta V = 12\text{ В} - (V_{f\_LED} + V_{f\_diode}) - V_s \approx 12 - 2.0 - 0.7 - 7.5 = 1.8\text{ В} > 0$$
Прямое смещение внутренних диодов верхних ключей во всех отключенных полумостах (`Hi-Z / Floating`) приводило к протеканию паразитного тока утечки через выключенные светодиоды в шину $V_s$. **В результате светились все 10 светодиодов одновременно.**

---

### 1.2. Решение: Аппаратная топология «Вариант 2»
Для физического устранения паразитной засветки питание общего анода светодиодов перенесено с внешних $+12\text{ В}$ на верхний силовой ключ драйвера **`NXP MC33879A`** (`OUT1`, клемма **`XP2:1`**, координата матрицы `D0`).

1. **Анод светодиодной гребенки**: подключается к **`XP2:1`** (`D0`, шина `+V2`).
2. **Катод целевого светодиода**: подключается к **`XP3:7`** (`PO3 / HB3`, линия `E6`, точка `TP41`).
3. **Условие запирания диодов**: 
$$V_{анод} = V_{OUT1} \le V_{s(TLE94112)}$$
Внутренние защитные High-Side диоды всех остальных отключенных полумостов `PO1..PO10` гарантированно заперты обратным смещением:
$$V_{anode\_diode} = V_{anode\_LED} - V_{f\_LED} \approx 8.75\text{ В} - 2.0\text{ В} = 6.75\text{ В} \le V_s$$
**Ток утечки равен строго 0.00 мА. Светится исключительно один выбранный канал `XP3:7`.**

### 2.1. Контроллер питания TI TPS65261 (D3) и потенциометры MCP4532 (DA2, DA3)
* **TPS65261** — трехканальный синхронный понижающий DC-DC преобразователь.
  * **Канал 1 (`+V1`)**: питает логику и силовые каскады $V_{S1}/V_{S2}$ микросхемы `TLE94112EL` через защитный мост `VD24`. Уставка `DA2 (0x2C) wiper = 2` обеспечивает $V_1 \approx 7.82\text{ В}$, что после падения на диодах дает стабильные $6.3\text{ В}$ на выводах чипа (запас выше порога отключения $V_{S\_UV} \approx 5.0\text{ В}$).
  * **Канал 2 (`+V2`)**: формирует силовое напряжение $V_{PWR}$ драйвера `MC33879A`. В штатном режиме домофона уставка держалась на уровне `wiper = 10` ($4.78\text{ В}$). Для работы со светодиодами стенда уставка переведена в **`wiper = 1`**, что подняло выходное напряжение до **$8.75\text{ В}$**.
  * **Управление включением**: осуществляется через биты расширителя `TCA9535` (`P0.2 = V2EN`, `P0.3 = V1EN`).

### 2.2. Расширитель портов TI TCA9535 (DD3)
* Адрес на шине I2C: **`0x20`**.
* Управляет линиями разрешения преобразователей:
  * `P0.2 (V2EN) = 1`: запуск шины `+V2` для питания микросхемы `MC33879A`.
  * `P0.3 (V1EN) = 1`: запуск шины `+V1` для питания `TLE94112EL`.
  * `P0.1 (PGOOD)`: контроль флага готовности питания (Power Good).

### 2.3. Драйвер верхних ключей NXP MC33879A (D1)
* **Интерфейс**: SPI Mode 1 (CPOL=0, CPHA=1), CS = GPIO8, тактовая частота 1 МГц, формат кадра — 16 бит MSB-first.
* **Аппаратные особенности**:
  * Прямые входы параллельного управления **`IN5` (GPIO27)** и **`IN6` (GPIO21)** принудительно сконфигурированы микроконтроллером в `GPIO_MODE_OUTPUT` со стабильным уровнем `LOW (0)`. Это исключает самопроизвольное аппаратное замыкание каналов `OUT5` и `OUT6` по логическому «ИЛИ».
  * Линия **`EN-DE` (GPIO20)** удерживается в `HIGH (1)`.
* **Командный кадр SPI**:
  * Байт 0 (`0x00`): отключение токов тестирования обрыва цепи (Open Load Detect Currents).
  * Байт 1 (`0x01`): включение ключа `OUT1` (`D0`, клемма `XP2:1`) в режиме High-Side.
  * Результирующий 16-битный кадр: **`0x0001`**.

### 2.4. 12-полумостовой драйвер Infineon TLE94112EL (D2)
* **Интерфейс**: SPI Mode 1 (CPOL=0, CPHA=1), CS = GPIO10, формат данных — 16 бит **LSB-first**.
* **Разводка выходов на клеммник XP3**:
  * Линия единиц **`E6`** матрицы разведена на полумост **`PO3` (HB3 / pin 14 D2)** и выведена на клемму **`XP3:7`** (контрольная точка **`TP41`**).
* **Состояние регистра активации (`HB_ACT_1_CTRL`)**:
  * `HB3_HS_EN = 0`, `HB3_LS_EN = 1` $\rightarrow$ полумост переведен в режим **Low-Side ON** (открыт n-канальный транзистор на `GND`). Сопротивление открытого канала $R_{DS(on)} \approx 0.8\text{ Ом}$.
  * Все остальные полумосты (`HB1, HB2, HB4..HB12`): биты `HS=0, LS=0` $\rightarrow$ состояние **Hi-Z (Floating)**.

## 3. Временные диаграммы и осциллограммы работы (Timing Diagrams)

### 3.1. Последовательность инициализации и включения тракта

```
               t0      t1      t2      t3      t4      t5      t6
               |       |       |       |       |       |       |
POWERIN (+12V) +------------------------------------------------------------> 11.64V
               |       |       |       |       |       |       |
V1EN (P0.3)    +-------+----------------------------------------------------> HIGH
               |       |       |       |       |       |       |
+V1 Bus        +---------------+--------------------------------------------> 7.82V
               |       |       |       |       |       |       |
V2EN (P0.2)    +-------+----------------------------------------------------> HIGH
               |       |       |       |       |       |       |
+V2 (wiper=1)  +---------------+--------------------------------------------> 8.75V
               |       |       |       |       |       |       |
EN-DE (GPIO20) +---------------+-------+------------------------------------> HIGH (Wakeup)
               |       |       |       |   t_wakeup (>10ms)    |
               |       |       |       |<--------------------->|
MC33 CS (IO8)  ======================================================+--+--->
                                                                     |  | SPI Frame 0x0001
                                                                     +--+
XP2:1 (D0)     ---------------------------------------------------------+---> 8.75V (High-Side)
                                                                        |
TLE CS (IO10)  =============================================================+--+->
                                                                            |  | LSB Frame HB3=LS
                                                                            +--+
XP3:7 (PO3)    ================================================================-+-> 0.05V (GND)
                                                                                |
LED Current    -----------------------------------------------------------------+-> 41.8 mA
```

* **Интервал $t_0 \dots t_1$**: Включение преобразователей TPS65261 через регистры расширителя TCA9535 (`V1EN=1`, `V2EN=1`).
* **Интервал $t_1 \dots t_2$**: Установка цифровых потенциометров MCP4532: `DA2` (wiper=2 $\rightarrow$ 7.82 В), `DA3` (wiper=1 $\rightarrow$ 8.75 В). Выход на установившийся уровень.
* **Интервал $t_2 \dots t_3$**: Активация общего аппаратного вывода разрешения `EN-DE (GPIO20) = 1`.
* **Интервал $t_3 \dots t_4$**: Пауза пробуждения $t_{wakeup} = 15\text{ мс}$ (превышает требуемые по даташитам $t_{sleep\_exit} \le 10\text{ мс}$ для обоих чипов).
* **Интервал $t_4 \dots t_5$**: SPI-транзакция к MC33879A: включение верхнего ключа `OUT1` (`D0`). Потенциал клеммы `XP2:1` возрастает до **$+8.75\text{ В}$**.
* **Интервал $t_5 \dots t_6$**: SPI-транзакция к TLE94112EL: включение нижнего ключа `HB3` в `Low-Side ON`. Потенциал клеммы `XP3:7` опускается до **$0.05\text{ В}$ относительно GND**.
* **Точка $t_6$**: Замыкание силовой петли светодиода. Установившийся ток через измеритель INA226 DD6 составляет **41.8 мА**.

## 5. Выводы и регламент эксплуатации
1. **Безопасность полумостов**: Использование шины `+V2` с потенциалом $8.75\text{ В}$ полностью исключает риск протекания неконтролируемых сквозных токов через полумосты `TLE94112EL`.
2. **Селективность коммутации**: Обеспечена 100% избирательность — включение любого координатного перекрестка матрицы $D_n \times E_m$ активирует строго один абонентский узел без паразитных связей.
3. **Готовность исходного кода**: Тестовый модуль успешно верифицирован в `17_tle94112_chaser_test` и полностью готов для бесшовного переноса в боевой автомат коммутатора `Comutator / main.c`.
