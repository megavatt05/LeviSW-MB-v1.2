# Анализ связки MC33879 + ADG1608 + TLE94112 в матрице LeviSW-MB v1.2

**Дата актуализации:** 2026-11-26  
**Рабочая ветка:** `docs/hardware-reference`  
**Основа:** КД LeviSW-MB_v1.2E2[A], аппаратные документы аудита, BSP/примеры `fix/safety-driver-audit`, отчёт стендового LED-теста и даташиты производителей.  
**Целевая трубка:** обычная аналоговая ELTIS A5.  
**Статус:** функции отдельных узлов и LED-контур частично подтверждены; полный речевой маршрут A5 и его электрическая совместимость не доказаны.

## 1. Главный вывод и исправление прежнего описания

Три микросхемы выполняют разные функции:

- **ADG1608** — аналоговый мультиплексор 8:1. Выбирает одну из линий `AMP1…AMP8` и соединяет её с общим аналоговым входом `D`, на который через защитный элемент подаётся `+LINE`.
- **MC33879** — восьмиканальный силовой драйвер с аппаратно задаваемой конфигурацией high-side/low-side. Его выходные каналы в матрице связаны с `D0…D7` на `XP2:1…8`.
- **TLE94112EL** — двенадцатиканальный драйвер полумостов. Десять назначенных выходов формируют координаты `E0…E9` на `XP3:1…10`.

**Исправление:** `AMP1…AMP8` и `D0…D7` — разные именованные сети и разные стороны аппаратных каскадов. ADG1608 не является селектором D0…D7 и не подключает свои S1…S8 непосредственно к XP2. Утверждение прежней версии этого документа, что ADG1608 S1…S8 образуют координаты D0…D7, было ошибочным.

По проектным данным узла 10 предполагается дополнительное функциональное сопряжение AMP и D через `RN24/RN25`, `SW-OFS`, MC33879 и защитные диоды `VD15…VD22`. Точный pin-to-pin маршрут и физический вариант монтажа на экземпляре платы пользователя пока не подтверждены. Не считать AMP и D ни одной и той же сетью, ни гарантированно изолированными друг от друга без проверки полного нетлиста.

## 2. Аналоговый вход и координата AMP: ADG1608

Подтверждённый по схемной документации маршрут:

`XS1:8 (+LINE) → VD6 → ADG1608:D → выбранный S1…S8 → AMP1…AMP8 → XS3 / внешний узел LeviAMP`

| Канал ADG1608 | Сеть после аналогового ключа | Интерфейс |
|---|---|---|
| S1 | AMP1 | XS3 / LeviAMP |
| S2 | AMP2 | XS3 / LeviAMP |
| S3 | AMP3 | XS3 / LeviAMP |
| S4 | AMP4 | XS3 / LeviAMP |
| S5 | AMP5 | XS3 / LeviAMP |
| S6 | AMP6 | XS3 / LeviAMP |
| S7 | AMP7 | XS3 / LeviAMP |
| S8 | AMP8 | XS3 / LeviAMP |

Управление ADG1608:
- SW-A0 = TCA9535 P0.6;
- SW-A1 = TCA9535 P0.7;
- SW-A2 = TCA9535 P1.0;
- SW-EN = TCA9535 P1.1.

ADG1608 — двунаправленный аналоговый ключ. Он сам не формирует питание, не усиливает речь и не выполняет силовую коммутацию абонентской нагрузки. Аналоговые уровни на его выводах должны оставаться в пределах шин питания микросхемы. Реальные значения `+Vp`, `+LINE` и речевых/вызовных сигналов необходимо измерить.

## 3. Координата D: MC33879 и XP2

Программная карта и схемные документы связывают выходы MC33879 с координатами D:

| Канал MC33879 | Линия матрицы | Контакт XP2 |
|---|---|---|
| OUT1 / S1 | D0 | XP2:1 |
| OUT2 / S2 | D1 | XP2:2 |
| OUT3 / S3 | D2 | XP2:3 |
| OUT4 / S4 | D3 | XP2:4 |
| OUT5 / S5 | D4 | XP2:5 |
| OUT6 / S6 | D5 | XP2:6 |
| OUT7 / S7 | D6 | XP2:7 |
| OUT8 / S8 | D7 | XP2:8 |

SPI и разрешение:
- CS2 = GPIO8;
- MOSI = GPIO7;
- MISO = GPIO9;
- SCLK = GPIO5;
- общий EN-DE = GPIO20.

У MC33879 отдельные выводы Drain и Source. Режим определяется внешним соединением этих выводов, а не командой SPI:
- high-side конфигурация: Drain подключён к VPWR/положительной шине, Source — к нагрузке;
- low-side конфигурация: Drain подключён к нагрузке, Source — к GND.

SPI-команда включает или выключает OUT1…OUT8. Она не переключает физическую топологию канала между high-side и low-side.

По NXP MC33879A диапазон VPWR, в котором гарантируется полный рабочий режим, начинается с **5,5 В**. Порог undervoltage shutdown имеет диапазон 3,0…5,0 В (типовое значение 4,0 В). Поэтому факт, что конкретный экземпляр ещё не отключился при VPWR ниже 5,5 В, не доказывает соблюдение гарантированных параметров.

### IN5/IN6

IN5 и IN6 аппаратно объединяются логической функцией OR с командами соответствующих SPI-каналов OUT5/OUT6. Для чистого SPI-управления эти входы должны быть LOW.

Пользователь подтвердил для осмотренного экземпляра платы: сборка CORN13/RN13, связывающая указанные GPIO с IN5/IN6, не установлена; оба входа на выводах микросхемы подтверждены в LOW. Это снимает риск независимого включения OUT5/OUT6 через эти входы для подтверждённого состояния платы, но не отключает сами каналы 5/6.

Встречающиеся в старых примерах комментарии о прямом управлении IN5/IN6 через GPIO27/GPIO21 не соответствуют подтверждённой пользователем комплектации конкретной платы.

## 4. Координата E: TLE94112EL и XP3

| Координата | Выход TLE94112EL | Контакт XP3 |
|---|---|---|
| E0 | PO1 / HB1 | XP3:1 |
| E1 | PO5 / HB5 | XP3:2 |
| E2 | PO7 / HB7 | XP3:3 |
| E3 | PO9 / HB9 | XP3:4 |
| E4 | PO6 / HB6 | XP3:5 |
| E5 | PO4 / HB4 | XP3:6 |
| E6 | PO3 / HB3 | XP3:7 |
| E7 | PO10 / HB10 | XP3:8 |
| E8 | PO11 / HB11 | XP3:9 |
| E9 | PO8 / HB8 | XP3:10 |

У каждого используемого полумоста три допустимых рабочих состояния:
- **HS** — выход подключён к VS;
- **LS** — выход подключён к GND;
- **FLOATING / Hi-Z** — оба плеча отключены.

Режим LS для выбранного канала пользователь подтвердил; в LED-тесте PO3/HB3 (E6) используется как сток к GND. Это не доказывает, что E6 является возвратным проводом трубки A5. В штатной реализации нельзя считать TLE94112 прозрачным аналоговым мультиплексором или усилителем речевого сигнала.

PO2/HB2 и PO12/HB12 заняты отдельными служебными сетями и не являются обычными координатами E0…E9.

## 5. Что действительно подтверждает стендовый LED-тест D0 × E6

В `matrix_switching_hardware_report.md` из ветки `fix/safety-driver-audit` описан стендовый контур:

- анод тестового LED подключён к XP2:1 / D0;
- катод — к XP3:7 / E6;
- MC33879 OUT1 включён как high-side источник;
- TLE94112 PO3/HB3 включён как low-side сток.

Путь тока в рамках испытанной LED-сборки:

`+V2 → MC33879 OUT1 / D0 / XP2:1 → тестовая LED-нагрузка с резистором → TLE94112 PO3 / E6 / XP3:7 → GND`

В отчёте приведены вход платы 11,64 В, +V2 = 8,75 В, +V1 = 7,82 В, уровень D0 около 8,75 В, уровень E6 около 0,05 В и ток LED-нагрузки 41,8 мА. Внешний резистор стенда указан около 160 Ом.

Этот опыт подтверждает только работу конкретной силовой комбинации с конкретной LED-нагрузкой при повышенной шине +V2. Он **не** подтверждает:
- работу MC33879 при штатной уставке DA3;
- электрическую совместимость с трубкой A5;
- передачу и приём речи;
- вызов, отбой и открывание двери;
- соответствие D0×E6 реальной квартире.

В программной матрице последовательная тестовая карта относит квартиру 47 к D4×E6, тогда как LED-отчёт называет свой тестовый стенд D0×E6 «квартирой 47». Это расхождение уже отмечено в документации Matrix Manager. Ни одна из этих записей не заменяет реальную физическую карту 80 абонентов.

## 6. Питание MC33879: критическая незакрытая проверка

В проекте обнаружено несоответствие настроек DA3 (+V2 / VPWR):
- BSP Kconfig задаёт DA3 Wiper = 10 по умолчанию; комментарий обещает около 5,5–6,7 В;
- LED-отчёт называет для Wiper = 10 приблизительно 4,78 В;
- пример 17 `tle94112_chaser_test` указывает, что Wiper = 10 давал около 4,34 В и PGOOD = 0, поэтому программа переводит DA3 на Wiper = 2 (~7,8 В), а Wiper = 3 (~7,0 В) рассматривает как другой профиль;
- пример 16 `mc33879a_power_test` перед запуском драйвера принудительно выставляет Wiper = 1; в LED-отчёте для этой уставки измерено 8,75 В.

Значения из комментариев/отчётов расходятся и пока не сведены в один протокол измерений. Однако если Wiper = 10 действительно даёт 4,34–4,78 В, это ниже минимальных 5,5 В гарантированного рабочего диапазона MC33879A.

**Вывод:** оба просмотренных стендовых приложения меняют DA3 до включения силовых драйверов. Поэтому их успешная работа не подтверждает работу MC33879 с BSP-уставкой по умолчанию. Нельзя использовать Wiper = 10 как штатную уставку без измерения +V2 и непосредственно VPWR на D1.

Подробный разбор и программа проверки: [MC33879_VPWR_OPERATING_RANGE_AUDIT.md](MC33879_VPWR_OPERATING_RANGE_AUDIT.md).

## 7. Как соотносятся AMP, D и E

Функционально в проекте предполагается следующая архитектура:

1. ADG1608 выбирает входной аналоговый маршрут `+LINE → AMPn`.
2. MC33879 управляет силовым состоянием координаты `Dn` на XP2.
3. Проектные данные узла 10 описывают возможное сопряжение AMPn с Dn через `RN24/RN25`, `SW-OFS`, `VOH-UP/DN`, `VOD1…VOD8` и защитные диоды `VD15…VD22`.
4. TLE94112 управляет координатой `Em` на XP3, выбирая HS/LS/Hi-Z в зависимости от режима матрицы.

Пункты 1 и 2 подтверждаются разделением именованных сетей и функциями микросхем. Пункт 3 пока является проектной функциональной интерпретацией; необходимы точная схема узла 10, проверка посадочных мест RN24/RN25, трассировка каждого вывода и прозвонка реальной платы. Пункт 4 подтверждён таблицей выходов и API драйвера, но конкретный режим речевой линии не установлен.

**Критический вопрос:** каким образом внешний блок LeviAMP, аналоговый AMP-маршрут, цепь VOffset, силовые выходы D и координаты E совместно образуют двухпроводный контур Ln+/Ln− A5? Необходимо восстановить и прямой, и обратный токовый путь; не предполагать, что D0/E6 сами по себе являются готовой парой трубки.

## 8. Возврат -LINE

Пользователь подтвердил для своей платы цепь:

`-LINE → (L3 = 1 мГн || R23 = 1 Ом) → GND`

L3 и R23 подключены параллельно. Это не прямое 0-омное соединение -LINE с землёй и не доказательство возврата через выбранный выход TLE94112.

Полный путь от этой сети до клеммы `Ln−` A5 и его взаимодействие с E-координатой не прослежены. Нужно подтвердить по исходной КД/PCB и затем измерить на безопасном эквиваленте нагрузки.

## 9. Нужен ли MC33879?

**Для испытанной силовой координатной функции D/E MC33879 нужен**, если требуется формировать положительное питание на выбранной D-линии при high-side конфигурации, как в LED-контуре.

**Для одного лишь выбора входного аналогового сигнала +LINE среди AMP1…AMP8 MC33879 не нужен:** эту функцию выполняет ADG1608.

Но этого недостаточно, чтобы рекомендовать оставить или удалить MC33879 из проекта полностью. Пока неизвестны окончательная электрическая роль узла VOffset, все режимы LeviAMP и полный контур A5. Решение об удалении MC33879 принимать нельзя до завершения трассировки AMP/SW-OFS/D и анализа всех режимов.

## 10. Безопасный порядок следующей проверки

1. Проверить монтаж RN24/RN25 и RN22/RN23/RN26 на реальной плате; не считать данные другой ветки доказательством комплектации конкретного экземпляра.
2. По листу D8 и узлу 10 проследить выводы Drain/Source MC33879, сети AMP, SW-OFS, VOH-UP/DN, VOD1…VOD8, VD15…VD22 и D0…D7.
3. Отдельно подтвердить фактическую уставку DA3 и измерить +V2/VPWR D1 при Wiper = 10, затем сравнить с профилями Wiper = 2 и Wiper = 1 на токограниченном стенде без A5.
4. Подтвердить напряжения VS1/VS2 непосредственно на TLE94112 и не считать значение +V1 равным напряжению на выводах микросхемы без учёта VD24.
5. Проверить D/E на эквиваленте нагрузки, контролируя ток, напряжение, выбросы и отсутствие нежелательной подпитки выключенных каналов.
6. Получить КД внешнего узла LeviAMP, установить функцию SOUND1/SOUND2, ENAMP1…3, +Vamp, ALARM и путь приёма речи.
7. Восстановить оба проводника A5 до Ln+/Ln−, затем составить режимную таблицу покоя, вызова, снятия трубки, разговора, отбоя и двери.
8. Не подключать реальную A5 и не разрешать физическую матрицу до закрытия критических вопросов HW-001…HW-010, HW-014 и HW-015.
