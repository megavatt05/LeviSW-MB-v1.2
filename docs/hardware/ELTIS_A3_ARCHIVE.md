## Исторические сведения об A3 

Исходный документ содержал анализ фотографии разобранного экземпляра A3. На фотографии были видны два винтовых контакта, красно-синие провода, отдельная пара красно-чёрных проводов к динамическому излучателю и ещё одна пара красно-чёрных проводов с неустановленным назначением. Это визуальные наблюдения по конкретной фотографии, а не подтверждённая схема A5.

Для того экземпляра A3 оставались неподтверждёнными:
- полярность винтовых контактов;
- электрическая схема платы;
- назначение нижней пары проводов;
- внутреннее соединение контактов с компонентами;
- точные параметры микрофонного и разговорного узлов.

Цвет проводов не является обозначением полярности. Предположения по фотографии не следует использовать для подключения трубки.
