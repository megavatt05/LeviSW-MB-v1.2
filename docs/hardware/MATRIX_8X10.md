# Физическая матрица абонентов 8×10 LeviSW-MB v1.2

Статус: **электрические линии D/E частично подтверждены по схеме; соответствие 80 квартир физическим выходам не подтверждено**.

## 1. Координатная модель

Матрица имеет 8 линий координаты D и 10 линий координаты E:

- D0…D7 — восемь линий;
- E0…E9 — десять линий;
- потенциальное число координатных комбинаций: 8 × 10 = 80.

Сам факт наличия 80 комбинаций не устанавливает физический адрес квартиры. Номер квартиры нельзя выводить из порядка каналов или номера контакта разъёма без исходной адресной таблицы/прозвонки.

## 2. Координата D — ADG1608 и XP2

По листу D8 (PDF-страница 5) и общей схеме:

| Координата | Канал ADG1608 | Сеть | Разъём |
|---|---|---|---|
| D0 | S1 | AMP1 / D0 | XP2:1 |
| D1 | S2 | AMP2 / D1 | XP2:2 |
| D2 | S3 | AMP3 / D2 | XP2:3 |
| D3 | S4 | AMP4 / D3 | XP2:4 |
| D4 | S5 | AMP5 / D4 | XP2:5 |
| D5 | S6 | AMP6 / D5 | XP2:6 |
| D6 | S7 | AMP7 / D6 | XP2:7 |
| D7 | S8 | AMP8 / D7 | XP2:8 |

Управление ADG1608:
- TCA9535 P0.6 — SW-A0;
- TCA9535 P0.7 — SW-A1;
- TCA9535 P1.0 — SW-A2;
- TCA9535 P1.1 — SW-EN.

Эта таблица фиксирует соответствие каналов и платных сетей, а не физические номера квартир.

## 3. Координата E — TLE94112EL и XP3

По листу E10 (PDF-страница 6):

| Координата | Выход TLE94112EL | Разъём |
|---|---|---|
| E0 | PO1 | XP3:1 |
| E1 | PO5 | XP3:2 |
| E2 | PO7 | XP3:3 |
| E3 | PO9 | XP3:4 |
| E4 | PO6 | XP3:5 |
| E5 | PO4 | XP3:6 |
| E6 | PO3 | XP3:7 |
| E7 | PO10 | XP3:8 |
| E8 | PO11 | XP3:9 |
| E9 | PO8 | XP3:10 |

Дополнительно:
- PO2 выведен на SW-OUT2 и в общей схеме связан с цепью OpenDoor через R1 (0 Ом).
- PO12 выведен на SW-OUT12.

TLE94112EL — драйвер полумостов. До измерений нельзя считать E0…E9 пассивными контактами или прозрачными аналоговыми ключами.

## 4. Таблица физических адресов квартир

Существующую физическую адресную карту нельзя перенумеровывать. Заполнять эту таблицу только из исходного документа адресации или по протоколу прозвонки.

| Квартира | D-линия | E-линия | XP2 | XP3 | Подтверждение |
|---:|---|---|---|---|---|
| 1–80 | Не заполнено | Не заполнено | Не заполнено | Не заполнено | Требуется исходная карта/прозвонка |

Не генерировать автоматически предположительную нумерацию 1…80 как будто она соответствует физической разводке.

## 5. Протокол проверки физической матрицы

Для каждого адреса записывать:
- номер квартиры из исходной адресной ведомости;
- физический кабель/клемму;
- D-координату и точку XP2;
- E-координату и точку XP3;
- результат прозвонки при обесточенной плате;
- сопротивление/изоляцию относительно соседних линий и GND;
- ревизию платы, исполнение жгута, дату и исполнителя;
- фото/файл доказательства.

Проверять только на обесточенной плате с отключёнными внешними линиями. Не подавать тестовое напряжение до анализа защитных цепей и возможных путей через полупроводники.

## 6. Программный интерфейс будущей адресной карты

В прошивке адрес квартиры должен быть логическим ключом, который разрешается в пару физических координат через отдельную конфигурационную таблицу. Номера GPIO, индексы ADG1608, выходы TLE94112 и номера квартир нельзя смешивать в одном массиве без типизации и валидации.

Физический режим по умолчанию должен оставаться закрытым, пока все 80 записей не имеют подтверждённого статуса и не пройдены тесты отсутствия одновременного выбора несовместимых линий.
