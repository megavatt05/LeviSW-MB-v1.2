# LeviSW-MB v1.2 — Пакет поддержки платы (BSP) для ESP-IDF

Компонент поддержки платы (Board Support Package) для контроллера домофонной матрицы **LeviSW-MB v1.2** (`U210001-A E3`, матрица `8 × 10` на 80 абонентов, MCU `ESP32-PICO-V3`).

Разработан для **ESP-IDF >= 5.2** (актуальные API: `driver/i2c_master.h`, `driver/spi_master.h`, `esp_adc/adc_oneshot.h`, `driver/gpio.h`).

## Подключение к проекту ESP-IDF

1. Скопируйте каталог `levisw-mb-v1.2` в папку `components/levisw-mb-v1.2` вашего проекта **или** укажите его в корневом `CMakeLists.txt` через `EXTRA_COMPONENT_DIRS`:

```cmake
cmake_minimum_required(VERSION 3.16)
list(APPEND EXTRA_COMPONENT_DIRS "${CMAKE_CURRENT_LIST_DIR}/bsp/levisw-mb-v1.2")
include($ENV{IDF_PATH}/tools/cmake/project.cmake)
project(my_intercom_fw)
```

2. Выберите целевой чип `esp32` (`ESP32-PICO-V3`) и при необходимости скорректируйте параметры в `idf.py menuconfig` → **`LeviSW-MB v1.2 BSP Configuration`**:
   - частота шины I2C-L (`CONFIG_LEVISW_I2C_FREQ_HZ`, по умолчанию `400000` Гц);
   - частоты SPI для `TLE94112EL` и `MC33879APEKR2` (по умолчанию `2000000` Гц);
   - начальные уставки потенциометров `DA2 (+V1)`, `DA3 (+V2)`, `DA4 (Uload)`.

## Быстрый старт

```c
#include "esp_log.h"
#include "levisw_mb_v1_2_bsp.h"

void app_main(void)
{
    ESP_ERROR_CHECK(levisw_bsp_init());

    /* Включаем шины +V1 и +V2 (стартовые уставки MCP4532 уже записаны при init) */
    ESP_ERROR_CHECK(levisw_bsp_power_set(true, true, false, false));

    bool pg = false;
    ESP_ERROR_CHECK(levisw_bsp_power_good(&pg));

    /* Чтение телеметрии +V1 (DD5 INA226 0x40) */
    float v_v1 = 0.0f, i_ma = 0.0f;
    ESP_ERROR_CHECK(levisw_bsp_ina226_read(LEVISW_INA_V1, &v_v1, NULL, &i_ma, NULL));
    ESP_LOGI("APP", "PG=%d, +V1=%.2f В, I=%.1f мА", pg, v_v1, i_ma);

    /* Выбор десятка D4 (0..7) и получение номера полумоста TLE94112 для единицы E7 */
    ESP_ERROR_CHECK(levisw_bsp_adg1608_select(4, true));
    uint8_t hb = levisw_bsp_unit_to_tle_hb(7); /* Вернёт 10 (PO10) */

    /* Разрешаем работу драйверов D1/D2 (GPIO20 EN-DE = 1) */
    ESP_ERROR_CHECK(levisw_bsp_drivers_enable(true));
    ESP_LOGI("APP", "Единица E7 -> полумост PO%u", hb);
}
```

## Топология матрицы `8 × 10` (Десятки `D0..D7` и Единицы `E0..E9`)

- **Десятки `D0..D7` (клеммник `XP2:1..8`)**: выбираются двоичным кодом `SW-A2..SW-A0` мультиплексора `DA1 ADG1608BR` (с выходов `S1..S8` на шину `D` через `DA1:8`) при `SW-EN = 1`.
- **Единицы `E0..E9` (клеммник `XP3:1..10`)**: подключены к выходам `PO1..PO12` драйвера `D2 TLE94112EL` в **нелинейном порядке** (оптимизация трассировки ПП):

| `E1` | `XP3:2` | `TP36` | `PO5` (pin 3) | `5` |

## Критические аппаратные особенности платы

1. **Порог `VS_UV` у `D2 TLE94112EL` (~5.5–6.0 В)**: питание силовой части `D2` и `D1` поступает от шины `+V1`. При уставке `DA2` слишком высокого сопротивления напряжение `+V1` падает ниже порога блокировки пониженного напряжения `TLE94112EL`, и выходы переходят в Hi-Z. Значение по умолчанию `CONFIG_LEVISW_DEFAULT_V1_WIPER=2` (~7.8 В) обеспечивает штатный запуск.
2. **Общий узел `IO27` (`RS-ON` / `SW1 MODE`) на осмотренном экземпляре**:
   - `IO27` соединён с `DD2 MAX13487 nSHDN` через `R11 = 1 кОм` и с кнопкой `SW1 MODE` через `R10 = 4.7 кОм`.
   - Пользователь подтвердил, что `CORN13/RN13` не установлена; физической связи `IO27 → MC33879 IN5` на этом экземпляре нет. Старое описание `D8-A5` как ветви IO27→IN5 не применять к фактической сборке.
   - При использовании `IO27` как выхода (`levisw_bsp_rs485_set_active(true)`) нельзя надолго замыкать `SW1` (если `IO27` в `LOW`, кнопка не читается; если `IO27` в `HIGH`, ток через `R10 = 4.7 кОм` безопасен ~0.7 мА, но напряжение на узле просядет при переключении в `INPUT`).
3. **Загрузка и страппинг `IO12 (MTDI / 1WRx)`**: `IO12` задаёт напряжение встроенного LDO флеш-памяти `VDD_SDIO` при старте ESP32 (`0` = 3.3 В, `1` = 1.8 В). На плате установлен pull-down `RN6` 10 кОм, однако внешняя линия `1-Wire` не должна подавать высокий уровень на `1WRx` в момент сброса MCU.
4. **Аппаратное смещение канала `eLOAD` (`DP1 LM22675`)**: `DD7 INA226` на плате не смонтирован (DNP), а в цепи обратной связи `DP1` на схеме предусмотрен узел компенсации. Уточняйте целевое напряжение `Uload` калибровкой по `TP162` перед включением `eLOADEN`.
