# Пример 04: Узел детекции статуса трубок LU1 / LU2 (LeviSW-MB v1.2)

Данный проект демонстрирует программный опрос и цифровую фильтрацию сигналов снятия абонентской трубки через аппаратный **Узел 04** («Узел детекции статуса трубок LU1 / LU2», Лист 3 принципиальной схемы `Com-485-LU-1W.SchDoc` платы **LeviSW-MB v1.2**).

Поддерживаемая среда: **ESP-IDF >= 5.2** (целевой микроконтроллер: `ESP32-PICO-V3`).

---

## Архитектура и схемотехника Узла 04

### 1. Схемотехническая реализация
Узел предназначен для надёжного определения положения трубки абонента (поднята / уложена) на клеммах `XP1:7 (LU1)` и `XP1:6 (LU2)` домофонной линии.

#### Основные компоненты схемы:
- **Двойной триггер Шмитта DD1 (`74LVC2G17GW,125`)**: обеспечивает чѐткое формирование цифровых уровней без дребезга и ложных срабатываний при медленно меняющемся напряжении в линии.
- **Высокоомные входные делители (`R2, R3 = 510 кОм` и `R7, R8 = 1 МОм`)**: снижают уровень входного напряжения до безопасных для логики значений.
- **Защитные диоды `VD1, VD2` (300 мА / 40 В)**: ограничивают выбросы напряжения, защищая входы микросхемы `DD1` от статического электричества и перенапряжений до шины `+3.3V`.
- **Фильтрующие конденсаторы `C3, C4` (18 пФ) и `C6` (100 нФ)**: подавляют высокочастотные наводки и помехи по линиям детекции.

#### Подключения к микроконтроллеру DD4 (`ESP32-PICO-V3`):
- **Сигнал `LU1` (Линия 1)**: поступает с выхода `1Y` микросхемы `DD1:6` на вход микроконтроллера `GPIO36` (`ADC1_CH0 / I36`). Контрольные точки: `TP7` (разъём `XP1`), `TP45` (вход), `TP50` (выход `DO1`).
- **Сигнал `LU2` (Линия 2)**: поступает с выхода `2Y` микросхемы `DD1:4` на вход микроконтроллера `GPIO37` (`ADC1_CH1 / I37`). Контрольные точки: `TP6` (разъём `XP1`), `TP46` (вход), `TP51` (выход `DO2`).

## Сборка и запуск примера

1. Откройте терминал с настроенным окружением ESP-IDF (>= 5.2):
```bash
cd examples/04_lu_detector
idf.py set-target esp32
idf.py build
```

2. Выполните прошивку и откройте монитор порта:
```bash
idf.py flash monitor
```
