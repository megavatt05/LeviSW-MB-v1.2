# Пример 15: Каналы цифрового управления и телеметрии MV1, MV1e, MV2 (LeviSW-MB v1.2)

Копия примера для сборки непосредственно из каталога BSP (`bsp/levisw-mb-v1.2/examples/15_mv_telemetry_channels`).
Демонстрирует управление потенциометрами `DA2, DA3, DA4` (`MCP4532`) и чтение телеметрии `INA226` (`DD5, DD6`) для шин `+V1`, `+V2` и `Uload` (Узел 15).
