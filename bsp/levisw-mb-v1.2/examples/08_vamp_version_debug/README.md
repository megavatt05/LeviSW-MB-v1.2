# Пример 08: Датчики VAMPOK, VersionPCB и интерфейсы отладки (LeviSW-MB v1.2)

Данный проект демонстрирует аппаратный мониторинг напряжения питания усилителя `VAmpM`, определение аппаратной версии платы `VersionPCB` через АЦП и использование отладочных интерфейсов `UART0` / `JTAG` через аппаратный **Узел 08** (Лист 4 `MCU-ESP.SchDoc` принципиальной схемы платы **LeviSW-MB v1.2**).

Поддерживаемая среда: **ESP-IDF >= 5.2** (целевой микроконтроллер: `ESP32-PICO-V3`).

---

## Архитектура и схемотехника Узла 08

### 1. Мониторинг напряжения усилителя (`VAmpM`)
- **Назначение**: непрерывный контроль напряжения питания дочерней платы усилителя (`+Vamp`) с помощью встроенного АЦП микроконтроллера.
- **Схема подключения**:
  - Сигнал заведён на вывод **`GPIO34 / ADC1_CH6`** (`LEVISW_PIN_VAMP_MON`, контрольные точки `TP81`, `TP94`).
  - Измерение производится через прецизионный резистивный делитель `R16 = 510 кОм` / `R17 = 75 кОм` с коэффициентом ослабления `~7.8` (реализуется функцией BSP `levisw_bsp_vamp_read_mv()`).

---

### 2. Определение версии печатной платы (`VersionPCB`)
- **Назначение**: аппаратное считывание идентификатора ревизии печатной платы при загрузке.
- **Схема подключения**:
  - Сигнал подключен к выводу **`GPIO14 / ADC2_CH6`** (`LEVISW_PIN_PCB_VERSION`, контрольные точки `TP82`, `TP92`, `TP107`).
  - *Примечание*: Вывод `GPIO14` на схеме разделяется с линией отладочного интерфейса `JTAG JTMS`. Делитель собран на резисторах `R18 = 75 кОм`, `R19 = 1 кОм` и `R22 = 4.7 кОм`.

---

### 3. Отладочные и диагностические интерфейсы (`XP5`, `XP4`)
- **Разъём прошивки и отладки `XP5` (UART0)**:
  - `U0TX` (`GPIO1`, контрольные точки `TP105`, `TP116`), `U0RX` (`GPIO3`, `TP106`, `TP117`), `BOOT` (`GPIO0`, `TP104`, pull-up `RN16` 10 кОм). Обратите внимание, что сборка `RN7 (U0-RS485)` на плате не устанавливается (`DNP`).
- **Разъём внутрисхемного отладчика `XP4` (JTAG)**:
  - Обеспечивает подключение JTAG-программатора к выводам `JTCK (GPIO13)` и `JTMS (GPIO14)`.

---

## Сборка и запуск примера

1. Откройте терминал с настроенным окружением ESP-IDF (>= 5.2):
```bash
cd examples/08_vamp_version_debug
idf.py set-target esp32
idf.py build
```

2. Выполните прошивку и откройте монитор порта через UART0 (`XP5`):
```bash
idf.py flash monitor
```
