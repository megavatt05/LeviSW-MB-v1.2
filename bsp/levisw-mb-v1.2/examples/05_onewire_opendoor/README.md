# Пример 05: Каскад 1-Wire и управления открытием двери (LeviSW-MB v1.2)

Данный проект демонстрирует работу интерфейса `1-Wire` и аппаратного узла отпирания электрозамка (`OpenD`) через аппаратный **Узел 05** ( Лист 3 `Com-485-LU-1W.SchDoc` и Лист 2 принципиальной схемы платы **LeviSW-MB v1.2**).

Поддерживаемая среда: **ESP-IDF >= 5.2** (целевой микроконтроллер: `ESP32-PICO-V3`).

---

## Архитектура и схемотехника Узла 05

### 1. Каскад интерфейса 1-Wire (OpenDoor / считыватели ключей)
Интерфейс предназначен для подключения цифровых ключей (Touch Memory / Dallas iButton) и считывателей через разъём `XP1:9 (Open/1W)`.

#### Основные особенности реализации:
- **Резисторная сборка `RN12` (GPIO-1W)**: установлена на плате для коммутации линий `1WRx` и `1WTx`. При этом резервные сборки `RN10` и `RN11` не устанавливаются (`DNP`).
- **Подключения к микроконтроллеру DD4 (`ESP32-PICO-V3` / JTAG пины)**:
  - **`1WRx` (Приём)**: подключен к `GPIO12 (MTDI)` через `RN12`. Контрольные точки: `TP57`, `TP90`.
    > *Важно*: Вывод `GPIO12` является пином настройки напряжения `VDD_SDIO` при загрузке ESP32 (`MTDI`). На плате предусмотрен аппаратный `pull-down` резистор `RN6` (10 кОм), гарантирующий низкий уровень при сбросе.
  - **`1WTx` (Передача)**: подключен к `GPIO15 (MTDO)` через `RN12`. Контрольная точка: `TP93`.

---

### 2. Узел аппаратного открытия замка (OpenD / SW-OUT2)
- **Аппаратная перемычка `R1` (0 Ом, SW-OpenDoor)**:  
  Объединяет линию отпирания замка `OpenD` (`XP1:9`, контрольная точка `TP17`) с выходом `SW-OUT2` (полумост `PO2` интегрального драйвера единиц `D2 TLE94112EL`, пин 23).
- **Принцип работы**:  
  По команде микроконтроллера через шину `SPI2` драйвер `D2 TLE94112EL` активирует полумост `PO2`, формируя мощный импульс напряжения на клемме `XP1:9`, что приводит к срабатыванию электромагнитного или электромеханического замка подъезда.

---

## Сборка и запуск примера

1. Откройте терминал с настроенным окружением ESP-IDF (>= 5.2):
```bash
cd examples/05_onewire_opendoor
idf.py set-target esp32
idf.py build
```

2. Выполните прошивку и откройте монитор порта:
```bash
idf.py flash monitor
```
